# Financial Consumer Complaint Analytics using Python and SQL

## Project Overview

This project analyzes financial consumer complaint data using Python, SQL, Pandas, and Matplotlib. The objective is to identify complaint trends, analyze company performance, study regional complaint distribution, and generate business insights.

## Technologies Used

* Python
* Pandas
* Matplotlib
* SQLite
* SQL

## Dataset

* Consumer Financial Protection Bureau (CFPB) Complaint Dataset
* Sample Size: 20,000 Records

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. SQL Analysis
5. Data Visualization
6. Business Insights

## Key Analyses

* Top Complaint Products
* Top Companies
* Top States
* Complaint Submission Channels
* Monthly Complaint Trends
* SQL-based Business Queries
