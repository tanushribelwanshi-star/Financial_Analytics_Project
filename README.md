# Financial Consumer Complaint Analytics using Python and SQL

## 📌 Project Overview

This project analyzes financial consumer complaint data using Python, SQL, Pandas, and Matplotlib. It demonstrates a complete data analytics workflow, including data cleaning, exploratory data analysis (EDA), SQL querying, and data visualization to identify complaint trends and generate business insights.

---

## 🎯 Objectives

- Clean and preprocess financial complaint data.
- Analyze complaint distribution across products, companies, and states.
- Study complaint submission channels.
- Analyze monthly complaint trends.
- Perform SQL-based analytical queries.
- Generate actionable business insights through visualization.

## 📈 Key Insights

- Credit reporting generated the highest number of complaints.
- Three major credit reporting companies received the majority of complaints.
- Texas and Florida recorded the highest complaint volumes.
- Most complaints were submitted through the web portal.
- Complaint trends were analyzed on a monthly basis.
